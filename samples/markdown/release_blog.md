# 🚀 widget-forge 2.0 — A New Chapter

Let's dive into what's new. It's not just a release — it's a rethink of how the whole thing
fits together. In today's fast-paced world, a *seamless* upgrade path is a testament to a team
that cares, and we’ve worked hard to make this one painless.

## ✨ Highlights at a Glance

We’ll delve into the details below, but here is the short version — fast, reliable, and
scalable, with a robust new core that lets you leverage everything you already know.

- **New splice engine** — em dashes like this one no longer scare us.
- **Encoding-aware** — BOMs and CRLF survive untouched.
- **Idempotent** — running it twice changes nothing the second time.
